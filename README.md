## Repository Structure

Each project folder contains:
- `problem_statement.md` — problem, objectives, assumptions, algorithm, flowchart, pseudocode, test cases, and conclusion
- `main.py` — Python source code
- `sample_output.txt` — sample execution output
- `output_screenshot.png` — sample output presented as a terminal-style image

The root folder also contains `Consolidated_Report.pdf`.

## How to Run in VS Code

1. Extract the ZIP file.
2. Open the extracted `Python-Activity-Based-Learning` folder in Visual Studio Code.
3. Install Python 3 if it is not already installed.
4. Open a project folder, then open `main.py`.
5. Open **Terminal → New Terminal**.
6. Run:
   ```bash
   python main.py
   ```
   On some Windows installations, use `py main.py`.
7. Enter the sample values or your own valid values when prompted.
